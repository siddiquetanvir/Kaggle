# Machine Learning & Data Science Workspace 🚀

A low-maintenance repository storing hands-on machine learning projects, competitive Kaggle benchmark solutions, data science pipelines, and coursework for **The University of Tokyo GCI World 2026** program.

## 🛠️ Stack & Libraries
* **Language:** Python
* **Data Handling:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn, XGBoost, LightGBM
* **Visualization:** Matplotlib, Seaborn
* **Tools:** Google Colab, Kaggle API, Jupyter Notebooks

## 📂 Project Organization
* **Kaggle Competitions:** Classification and regression models, feature engineering pipelines, and data preprocessing scripts.
* **GCI World 2026:** Weekly assignments, ML benchmark pipelines, and capstone projects from UTokyo's Matsuo-Iwasawa Laboratory.
* **Lab & Practice:** Algorithmic experiments, hyperparameter optimization tests, and standalone scripts.
